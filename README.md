# Emmanuel's Portfolio

My personal portfolio showcasing my projects, skills, and journey as a full-stack web developer and BS Information Technology student at the University of Cebu (Main), with graduation expected in 2027.

I enjoy building practical web applications and exploring UI/UX design while continuing to learn. I also have basic knowledge of networking and Cisco fundamentals.

Built with React, JavaScript, Vite, CSS, and SVG, featuring a responsive black-and-lime design with subtle animations.

## Projects

- **GarantiyAid** — My current capstone project, a social assistance management system for beneficiary records, assistance programs, and aid distribution.
- **CCS Sit-in Monitoring** — A system for managing computer laboratory reservations and student sessions.

## Run locally

```sh
npm install
npm run dev
```

To create a production build, run `npm run build`.
